# 🐦 Coucou Windows

✨ A lightweight Windows app built with passion and a little bit of magic.

## 🚀 Features
- ⚡ Fast and simple to use
- 🪟 Made for Windows 10 / 11
- 🎨 Clean, friendly interface
- 🔧 Easy to set up and run

## 📦 Getting Started
1. 📥 Clone or download this repo
2. 🛡️ Turn off Smart App Control / SmartScreen (see below)
3. ▶️ Run the app

## 🛡️ Launching on Windows
Windows may block unsigned apps. Disable Smart App Control and SmartScreen in Windows Security, then run the app.
